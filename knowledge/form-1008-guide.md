# Underwriting Transmittal Summary (Form 1008) Guide

> **DISCLAIMER**: This is educational guidance only. Form 1008 is completed by lenders for GSE loan delivery. Borrowers do not complete this form.

## Overview

The Uniform Underwriting and Transmittal Summary (Form 1008) is used by lenders when delivering loans to Fannie Mae or Freddie Mac. It summarizes the underwriting decision and key loan characteristics.

## Purpose

- Documents the underwriter's analysis and decision
- Provides standardized summary for GSE loan delivery
- Contains calculated ratios and risk factors
- Shows compensating factors when applicable

## Key Sections

### Section 1: Loan and Borrower Information

**Loan Information**
- [ ] Loan number
- [ ] Loan amount
- [ ] Loan purpose (Purchase, Refinance, Construction)
- [ ] Loan type (Conventional, FHA, VA, USDA)
- [ ] Amortization type
- [ ] Interest rate
- [ ] Loan term
- [ ] Lien position

**Property Information**
- [ ] Property address
- [ ] Property type (SFR, Condo, PUD, Co-op, MH, etc.)
- [ ] Number of units
- [ ] Occupancy type
- [ ] Year built
- [ ] Appraised value
- [ ] Sales price (if purchase)

### Section 2: Income Analysis

**Stable Monthly Income**
For each borrower:
- [ ] Base income
- [ ] Overtime
- [ ] Bonus
- [ ] Commission
- [ ] Self-employment income
- [ ] Other income
- [ ] **Total Stable Monthly Income**

### Section 3: Housing Expense

**Proposed Monthly Housing Expense**
- [ ] First mortgage P&I
- [ ] Other financing P&I (second mortgage)
- [ ] Hazard insurance
- [ ] Real estate taxes
- [ ] Mortgage insurance
- [ ] HOA dues
- [ ] Other (ground rent, special assessments)
- [ ] **Total Housing Expense**

### Section 4: Qualifying Ratios

**Key Ratios**
- [ ] **Housing Expense Ratio (Front-End DTI)**
  - Formula: Total Housing Expense ÷ Total Income
  - Conventional guideline: ≤ 28% (flexible)
  
- [ ] **Total Debt-to-Income Ratio (Back-End DTI)**
  - Formula: (Housing Expense + All Monthly Debts) ÷ Total Income
  - Conventional guideline: ≤ 36-45% (varies by loan type)
  
- [ ] **Loan-to-Value (LTV)**
  - Formula: Loan Amount ÷ Property Value
  - Affects PMI requirement and pricing
  
- [ ] **Combined LTV (CLTV)**
  - Formula: All Liens ÷ Property Value
  - Includes second mortgages, HELOCs

### Section 5: Assets

**Funds Required**
- [ ] Purchase price or payoff amount
- [ ] Closing costs
- [ ] Prepaid items
- [ ] PMI/MIP
- [ ] Discount points
- [ ] Other (credits, adjustments)
- [ ] **Total Funds Required**

**Funds Available**
- [ ] Liquid assets
- [ ] Gift funds
- [ ] Seller contributions
- [ ] Subordinate financing
- [ ] **Total Funds Available**

**Reserves**
- [ ] Months of reserves after closing
- [ ] Type of reserves (checking, savings, retirement)

### Section 6: Credit Evaluation

**Credit History Summary**
- [ ] Representative credit score(s)
- [ ] Credit score used for pricing
- [ ] Mortgage payment history (current, 30-day, 60-day, 90-day+)
- [ ] Other credit history summary
- [ ] Derogatory credit events (bankruptcy, foreclosure, short sale)
- [ ] Explanation of derogatory items

### Section 7: Appraisal Information

- [ ] Appraiser name and license
- [ ] Appraisal date
- [ ] Value approach used
- [ ] Comparable sales summary
- [ ] Any value conditions or repairs required
- [ ] Appraisal waiver used?

### Section 8: Risk Assessment

**AUS Findings**
- [ ] AUS used (DU, LP, manual)
- [ ] AUS recommendation (Approve/Eligible, Refer, etc.)
- [ ] AUS case file ID
- [ ] Key findings and conditions

**Compensating Factors**
(If ratios exceed guidelines)
- [ ] Significant liquid reserves
- [ ] Low LTV
- [ ] Minimal increase in housing payment
- [ ] Strong credit history
- [ ] Conservative debt usage
- [ ] Stable employment history
- [ ] Cash-out purpose (debt consolidation reducing payments)

### Section 9: Condition Clearance

**Prior to Documents**
- [ ] All conditions cleared before docs drawn?
- [ ] Outstanding conditions list

**Prior to Funding**
- [ ] All conditions cleared before funding?
- [ ] Final document review complete

### Section 10: Underwriter Certification

- [ ] Underwriter name
- [ ] Underwriter signature/date
- [ ] Underwriting decision (Approve, Suspend, Deny)
- [ ] Conditions (if any)

## Common 1008 Calculations

### Housing Expense Ratio
```
Front-End DTI = Monthly Housing Payment / Gross Monthly Income × 100
```

### Total DTI
```
Back-End DTI = (Housing Payment + Monthly Debts) / Gross Monthly Income × 100
```

### LTV
```
LTV = Loan Amount / Lesser of (Appraised Value, Purchase Price) × 100
```

### CLTV
```
CLTV = (First Mortgage + All Subordinate Liens) / Property Value × 100
```

### Reserves Calculation
```
Months of Reserves = Liquid Assets After Closing / Monthly PITI
```

## Underwriting Standards Reference

### Conventional (Fannie/Freddie)
- Max DTI: 45-50% with strong compensating factors
- Min credit score: 620 (higher for certain products)
- Reserves: 2-6 months for second homes/investment

### FHA
- Max DTI: 43% standard, higher with compensating factors
- Min credit score: 500-580 depending on LTV
- Reserves: Not typically required for 1-2 units

### VA
- No max DTI (residual income analysis)
- No min credit score (lender overlays apply)
- No reserves required

### USDA
- Max DTI: 41% housing, 41% total (waivers available)
- Min credit score: 640 for automated approval
- Reserves: Not required
