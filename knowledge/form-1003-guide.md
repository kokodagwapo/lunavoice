# Uniform Residential Loan Application (Form 1003) Guide

> **DISCLAIMER**: This is educational guidance for understanding the 1003 form. Never invent or guess Social Security numbers, income figures, or other personal information. All data must be provided directly by the borrower.

## Overview

The URLA (Uniform Residential Loan Application), also known as Fannie Mae Form 1003, is the standard mortgage application form used by nearly all lenders. It was redesigned effective March 1, 2021.

## Section 1: Borrower Information

### 1a. Personal Information
- [ ] Full legal name (as it appears on government ID)
- [ ] Alternate names used (maiden name, prior married names)
- [ ] Social Security Number (borrower must provide directly)
- [ ] Date of birth
- [ ] Citizenship status (U.S. Citizen, Permanent Resident Alien, Non-Permanent Resident Alien)
- [ ] Type of credit (Individual, Joint with spouse, Joint with other)

### 1b. Current Address
- [ ] Street address
- [ ] Unit/apt number if applicable
- [ ] City, state, ZIP
- [ ] Time at current address
- [ ] Housing status (Own, Rent, No primary housing expense)
- [ ] Monthly rent/housing expense amount

### 1c. Mailing Address (if different)
- [ ] Complete mailing address

### 1d. Previous Address (if less than 2 years at current)
- [ ] Previous address details
- [ ] Dates of residence
- [ ] Housing type at previous address

### 1e. Contact Information
- [ ] Home phone (optional)
- [ ] Cell phone
- [ ] Work phone (optional)
- [ ] Email address

## Section 2: Financial Information - Assets and Liabilities

### 2a. Assets - Bank Accounts
For each account:
- [ ] Account type (Checking, Savings, Money Market, CD, etc.)
- [ ] Financial institution name
- [ ] Account number (last 4 digits shown on application)
- [ ] Cash or market value

### 2b. Other Assets
- [ ] Retirement accounts (401k, IRA, Keogh)
- [ ] Stocks and bonds
- [ ] Life insurance net cash value
- [ ] Real estate owned
- [ ] Gifts (requires gift letter)
- [ ] Grants

### 2c. Liabilities
For each liability:
- [ ] Account type (Revolving, Installment, Mortgage, etc.)
- [ ] Company name
- [ ] Account number
- [ ] Unpaid balance
- [ ] Monthly payment
- [ ] Paid off at/before closing?

### 2d. Other Liabilities and Expenses
- [ ] Alimony
- [ ] Child support
- [ ] Separate maintenance
- [ ] Job-related expenses

## Section 3: Financial Information - Real Estate

### For Each Property Owned
- [ ] Property address
- [ ] Property value
- [ ] Intended occupancy (Primary, Secondary, Investment)
- [ ] Monthly insurance
- [ ] Monthly taxes
- [ ] HOA dues
- [ ] Monthly rental income (if applicable)
- [ ] Mortgage details (lender, balance, payment)

## Section 4: Loan and Property Information

### 4a. Loan and Property Information
- [ ] Loan purpose (Purchase, Refinance, Other)
- [ ] Property address
- [ ] Number of units
- [ ] Property value/purchase price
- [ ] Occupancy (Primary Residence, Second Home, Investment)
- [ ] Mixed-use property? (if yes, explain)
- [ ] Manufactured home?

### 4b. Other Loan Information
- [ ] Refinance: Original cost, year acquired, purpose, improvements
- [ ] Title held in what name(s)
- [ ] Manner title will be held
- [ ] Estate will be held in (Fee Simple, Leasehold, etc.)
- [ ] Native lands?

### 4c. Mortgage Loan Information
- [ ] Loan amount
- [ ] Loan purpose
- [ ] Loan type (Conventional, FHA, VA, USDA, Other)
- [ ] Amortization type (Fixed, ARM, GPM, Other)
- [ ] Loan term

## Section 5: Employment and Income

### 5a. Employment Information
For each employer (current and previous 2 years):
- [ ] Employer name
- [ ] Employer address
- [ ] Employer phone
- [ ] Position/title
- [ ] Start date
- [ ] End date (if applicable)
- [ ] Self-employed?
- [ ] Ownership share (if self-employed)

### 5b. Income
- [ ] Base monthly income
- [ ] Overtime
- [ ] Bonus
- [ ] Commission
- [ ] Military entitlements
- [ ] Other income (describe source)

### 5c. Self-Employment Income
- [ ] Business name
- [ ] Business address
- [ ] Monthly income

## Section 6: Declarations

Borrower must answer yes/no to:
- [ ] Outstanding judgments?
- [ ] Delinquent federal debt?
- [ ] Party to lawsuit?
- [ ] Conveyed title in lieu of foreclosure?
- [ ] Pre-foreclosure/short sale?
- [ ] Foreclosure in past 7 years?
- [ ] Bankruptcy in past 7 years?
- [ ] Current property foreclosure?
- [ ] Any part of down payment borrowed?
- [ ] Co-maker or endorser on any loan?

Occupancy questions:
- [ ] Will this be primary residence?
- [ ] Family/business relationship with seller?
- [ ] Borrowed money from anyone for this transaction?
- [ ] Applied for other mortgage for this property?
- [ ] Priority of new lien?

## Section 7: Military Service

- [ ] Currently serving or have served in U.S. Armed Forces?
- [ ] Type of service (Active Duty, Reserve, National Guard)
- [ ] Currently or ever activated?
- [ ] Projected retirement date

## Section 8: Demographic Information

(Government monitoring purposes - voluntary)
- [ ] Ethnicity
- [ ] Race
- [ ] Sex
- [ ] Method of collection

## Section 9: Loan Originator Information

(Completed by lender)
- [ ] LO name and NMLS ID
- [ ] LO organization name and NMLS ID
- [ ] LO address and contact info

## Section 10: Continuation Sheet

For additional information that doesn't fit in main sections

## Common Document Requirements

### Income Verification
- [ ] Pay stubs (most recent 30 days, all employers)
- [ ] W-2s (2 years)
- [ ] Tax returns (2 years, if self-employed or complex income)
- [ ] 1099s (if applicable)
- [ ] Social Security/retirement award letters

### Asset Verification
- [ ] Bank statements (2 months, all pages)
- [ ] Investment account statements
- [ ] Retirement account statements
- [ ] Gift letter and donor's bank statements (if using gift)

### Property Documentation
- [ ] Purchase contract
- [ ] Property listing (if applicable)
- [ ] HOA documents (if applicable)

### Identity
- [ ] Government-issued photo ID
- [ ] Social Security card (may be required)
